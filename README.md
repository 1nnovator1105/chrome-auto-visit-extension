# Auto Visit

정해둔 간격마다 목록에 넣은 링크를 **전부 한 번씩** 열어 주는 크롬 확장 프로그램입니다.
페이지가 살아 있는지 주기적으로 확인하는 **모니터링 용도**로 만들었습니다.

예: 링크 2개를 넣고 간격을 30초로 정하면, 30초마다 링크 2개가 각자의 탭에서 다시 열립니다.

## 주요 기능

- 링크 목록을 정해둔 간격(초·분·시간)마다 전부 한 번씩 열기
- 링크마다 전용 탭 하나를 재사용 (탭이 계속 늘어나지 않음)
- 방문할 때마다 **HTTP 상태 코드와 응답 시간** 기록
- 백그라운드 탭으로 열어 보던 화면 유지
- 크롬을 다시 켜도 실행 중이던 상태 그대로 이어서 동작

## 설치

크롬 웹 스토어에 올리지 않았으므로 **개발자 모드로 직접 설치**합니다.

1. 이 저장소를 내려받습니다.

   ```bash
   git clone https://github.com/1nnovator1105/chrome-auto-visit-extension.git
   ```

   git을 쓰지 않는다면 GitHub 페이지의 **Code → Download ZIP**으로 받아 압축을 풉니다.

2. 크롬 주소창에 `chrome://extensions` 를 입력합니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고, 내려받은 폴더(`manifest.json` 이 들어 있는 폴더)를 선택합니다.
5. 툴바의 퍼즐 아이콘을 눌러 **Auto Visit** 옆 핀을 꽂아 두면 쓰기 편합니다.

> 크롬 120 이상이 필요합니다.

### 업데이트

```bash
git pull
```

받은 뒤 `chrome://extensions` 에서 Auto Visit 카드의 새로고침(↻) 버튼을 누르면 바뀐 내용이 적용됩니다.

## 사용법

1. 툴바의 Auto Visit 아이콘을 눌러 팝업을 엽니다.
2. **방문할 링크**에 한 줄에 하나씩 링크를 입력합니다.

   ```text
   https://example.com
   example.com/health
   # 이 줄은 주석이라 건너뜁니다
   ```

   - `https://` 를 빼면 자동으로 붙습니다.
   - `#` 으로 시작하는 줄은 건너뜁니다. 잠깐 빼두고 싶은 링크에 쓰면 됩니다.
   - `http`, `https` 링크만 쓸 수 있습니다.

3. **방문 간격**을 정합니다. 숫자와 단위(초·분·시간)를 고르며, **최소 30초**입니다.
4. 보던 화면을 바꾸지 않으려면 **백그라운드 탭에서 열기**를 켜 둡니다 (기본값).
5. **시작**을 누릅니다.
   - 목록의 링크가 바로 한 번씩 열리고, 이후 간격마다 다시 열립니다.
   - 툴바 아이콘에 초록색 `ON` 배지가 붙습니다.
6. 실행 중 팝업에서 볼 수 있는 것
   - **마지막 방문**: 마지막으로 연 시각, 링크 개수, 몇 번째 반복인지
   - **다음 방문**: 다음에 열 시각과 남은 시간
   - **지금 전부 열기**: 다음 간격을 기다리지 않고 바로 한 번 엽니다
7. **정지**를 누르면 멈춥니다. 열어 둔 탭은 닫지 않고 그대로 둡니다.

실행 중에는 링크와 간격을 고칠 수 없습니다. 바꾸려면 정지 → 수정 → 다시 시작하세요.
입력하던 내용은 팝업을 닫아도 남아 있습니다.

## 방문 기록 읽는 법

팝업 아래 **방문 기록**에 최근 결과가 최신순으로 나옵니다.
최대 200건을 저장하고 팝업에는 50건까지 보여 줍니다. **지우기**로 비울 수 있습니다.

| 표시 | 뜻 |
|---|---|
| `200 · 0.8s` (초록) | 정상 응답. 뒤의 숫자는 응답 시간 |
| `503 · 1.2s` (빨강) | 서버가 4xx·5xx 오류로 응답 |
| `ERR_NAME_NOT_RESOLVED` 등 (빨강) | 네트워크 오류 (주소 없음, 연결 거부, 인증서 오류 등) |
| `미완료` (주황) | 다음 방문 때까지 로딩이 끝나지 않음 |
| `로딩 중…` (회색) | 지금 불러오는 중 |

응답 시간은 탭에 주소를 넣은 때부터 **메인 문서** 응답이 끝날 때까지입니다.
이미지·스크립트 같은 하위 리소스 로딩 시간은 들어가지 않습니다.

## 동작 방식과 주의할 점

- **간격은 최소 30초입니다.** 크롬이 확장 프로그램의 반복 타이머(`chrome.alarms`)를 30초보다 짧게 허용하지 않기 때문입니다.
- **링크마다 전용 탭이 하나씩** 생기고, 간격마다 그 탭에서 다시 엽니다. 탭을 닫으면 다음 간격에 새로 엽니다.
- 같은 링크를 목록에 두 번 넣으면 탭도 두 개가 됩니다.
- 로그인이 필요한 페이지는 **크롬에 로그인된 상태 그대로** 방문합니다.
- 컴퓨터가 잠자기 상태이거나 크롬이 꺼져 있으면 방문하지 않습니다.
- HTTP 상태 코드를 읽기 위해 **모든 사이트 접근 권한**을 요청합니다. 요청을 읽기만 하고 바꾸거나 막지 않으며, 기록은 이 브라우저 안에만 저장되고 외부로 보내지 않습니다.

## 권한

| 권한 | 쓰는 곳 |
|---|---|
| `storage` | 링크 목록, 실행 상태, 방문 기록 저장 |
| `alarms` | 정해둔 간격마다 방문 |
| `webRequest` + `<all_urls>` | 방문한 페이지의 상태 코드·응답 시간 기록 |

## 파일 구성

```text
manifest.json   확장 프로그램 설정 (Manifest V3)
background.js   서비스 워커 — 타이머, 탭 관리, 방문 기록
popup.html/css/js  툴바 팝업 화면
icons/          아이콘
```
